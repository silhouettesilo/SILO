SILO 3.0 RECOVERY BUILD — 2026-11-11

This build is reconstructed from the preserved SILO 2.0 Commercial Build and the
three source replacements in the SILO 2.1 Email Verification Upgrade. It is an
active recovery/development build, NOT a production or public-sale release.

PRESERVED FOUNDATION
- Express 5 application, SQLite persistence and additive migrations.
- Workspace-scoped tasks, customers, documents, automations, activity and proposals.
- Authentication, email verification, persistent sessions, CSRF protection,
  authentication/API rate limits, audit logging, backup and restore.
- Local Ollama AI Assistant and approval-based AI Employee.
- Existing Stripe checkout/webhook scaffolding and Resend email integration.
- Original dark SILO frontend and existing application workflows.

ADDED IN THIS RECOVERY PASS
- Database migrations 4–13: password-reset and email-change tokens, AI usage ledger, AI execution history,
  support ticket storage, Stripe webhook idempotency table, and optional MFA fields, workspace invitation storage, calendar events, reusable email templates, email drafts/sent history, reminder preferences, safe email send locks, monotonic Stripe subscription event tracking, and backup/restore data tables. Additive only.
- Password reset request and one-hour single-use token workflow, with non-enumerating
  response and Resend delivery (development links are logged locally only).
- Email address change with current-password confirmation, one-hour single-use verification,
  uniqueness checks and global session revocation after confirmation.
- Hourly cleanup of expired sessions, verification tokens, password-reset tokens and
  email-change tokens.
- Optional authenticator-app MFA: encrypted TOTP secrets, 30-second TOTP validation with
  replay protection, 10 hashed single-use recovery codes, MFA login challenge, disable flow,
  and second-factor checks for password/email changes, ownership transfer and account deletion.
- Password changes revoke other sessions; password reset revokes sessions.
- Account deletion with password confirmation and safeguards for shared workspaces
  and workspaces with an active Stripe subscription.
- Workspace member listing for owner/admin, plan-capped workspace creation, ownership transfer to an existing member, and workspace switching.
- Version 3 workspace backups include calendar, email, support and AI history data; restore validates and transactionally replaces the workspace data while preserving account/security and billing records.
- CSV export/import for tasks, customers and documents; CSV parsing, row validation,
  500-row/2MB limits, plan limits, and transaction rollback on invalid imports.
- Industry starter packs: hospitality, retail, professional services, technology,
  healthcare administration, education and general business.
- AI token usage ledger and approval/rejection execution history endpoints.
- Safe AI proposal undo snapshots: verifies all affected records still match the post-approval
  state before reversing anything; if any record changed, the entire undo is refused.
  Supports workspace records, task completion, unsent email drafts, and calendar events.
  Calendar undo is refused after a reminder is sent or a recurring child event is created;
  email undo is refused once the draft is changed, locked for sending, or sent.
- AI Employee can propose calendar events and customer email drafts; email sending remains
  a separate explicit owner/admin action. Safe undo now includes unsent drafts and calendar
  events, with guards against sent reminders, recurring child events, and email sending. Hosted OpenAI Responses API provider option,
  local Ollama provider option, and explicit
  operator-configured fallback provider. Responses API requests use store=false.
- Monthly workspace AI request quotas, operator-configured token cost estimates, and per-workspace monthly budget alerts (source implemented; provider delivery not yet tested).
- Support ticket submission, workspace-scoped owner/admin listing and status management.
- Stripe webhook duplicate-event protection and subscription/customer association checks;
  handles created/updated/deleted/paused/resumed and invoice.payment_failed events.
- Frontend password recovery flow, starter pack application, CSV tools, MFA setup/login, team invitations and role management, workspace creation/switching, calendar, templates and email draft UI.
- Production Dockerfile, Compose deployment template, persistent SQLite volume, non-root
  runtime user, and container health check.
